## Local Development

1. Clone the repository

```
git clone https://github.com/bhattpratin-blip/amba-ai-task-manager-v6-google-sheets-updated.git
```

2. Open

```
index.html
```

in your browser.

3. Login using the default credentials.

---

# ☁ Google Sheets Integration

1. Create a Google Apps Script project.

2. Deploy it as a Web App.

3. Copy the Deployment URL.

4. Replace

```javascript
const API_URL = "...";
```

inside

```
index.html
```

with your deployment URL.
